# Data
Adult (Census Income), UCI: https://archive.ics.uci.edu/dataset/2/adult
DOI: https://doi.org/10.24432/C5XW20
The script downloads the official adult.data and adult.test files from UCI.
If automatic download fails, download adult.zip from that page, extract it,
and place adult.data and adult.test in this directory. Keep the filenames unchanged.
Adult is the binary <=50K / >50K dataset, distinct from Census Income (KDD).
See the source page for attribution and license (CC BY 4.0).
